### Writing conventions
#### 1.  Writing
* All variables, functions, class names, ect. must be writen in <em><strong>english</strong></em>
* All strings must be double quotes <strong>""</strong>
* Must follow rules to create commands
#### 2. Naming 
* Variables: snake_case
* Constants and enum states: ALL_CAPS
* Functions: camelCase
* Classes and enum names: PascaleCase
* File names: lowercasenospaces
